客户端选择（重点）

MOCClouc 采用通用订阅格式，可在主流代理客户端中导入。选择原则很简单：桌面优先 Clash Meta / Mihomo，苹果手机优先 Shadowrocket 或 Surge，安卓优先 Clash Meta for Android 或类似兼容客户端，路由器走 OpenWrt 插件。先确定系统，再导入订阅，最后按延迟与用途挑节点。

Windows / macOS

推荐 Clash Meta（Mihomo）图形客户端。导入订阅后开启系统代理，规则模式用于浏览与办公，全局模式用于个别应用。游戏可单独走 IPLC 策略组。

Android

推荐 Clash Meta for Android。粘贴订阅地址，允许 VPN 权限后连接。建议开启绕过中国大陆 IP，减少不必要的流量消耗。

iOS / iPadOS

常用 Shadowrocket、Stash 或 Surge。App Store 安装完成后新增订阅，更新节点列表，按地区分组选择。流媒体请使用解锁标签所在节点。

路由器与网关

OpenWrt、iStoreOS 等可使用订阅转换后的配置。家庭共享时注意设备数上限：基础版 3 台、旗舰版 5 台、团队版 20 台。

客户端本身不由 MOCClouc 开发，请从各客户端官方渠道获取安装包。本站提供订阅兼容说明与官方下载入口索引，避免来路不明的改装包。

操作说明

第一步：确认需求并选择套餐

先数清同时在线的手机、电脑和路由器数量，再估算视频与下载用量。个人日常浏览选基础版，主力看流媒体或打游戏选旗舰版，多人共用选团队版。

第二步：开通并复制订阅

在官方用户中心完成开通后，复制 Clash / 通用订阅链接。不要把链接发到公开聊天，避免被他人滥用导致流量耗尽或设备挤占。

第三步：安装客户端并导入

打开客户端的订阅或配置页面，粘贴链接并更新。导入成功后应看到地区分组。若列表为空，检查链接是否完整、是否包含多余空格。

第四步：选择节点并验证

先连香港或新加坡做连通测试，能打开目标站点后再切到流媒体或 IPLC 分组。办公场景保持规则模式，仅对需要加速的域名走代理。

  4. 游戏或会议软件单独指定策略组。

常见问题

MOCClouc 是什么？和普通 VPN 客户端有何不同？

MOCClouc 是机场订阅服务：你购买的是可定期更新的节点与流量配额，再导入自己选择的客户端使用。它不是单一 App 内置线路，因此 Windows、macOS、Android、iOS 和路由器可以共用同一条订阅，按套餐限制同时在线。

如何选择客户端才不容易出错？

以系统生态为准：桌面用 Clash Meta，iOS 用 Shadowrocket 或 Surge，安卓用 Clash Meta for Android。不要混用来路不明的破解包。导入时选择与套餐面板一致的订阅类型，更新节点后再连接。

订阅链接导入失败怎么办？

先确认链接完整且未过期，删除首尾空格后重试。若客户端提示协议不支持，改用通用 Clash 订阅。公司网络拦截时，可更换 DNS 或改用客户端内置的远程更新方式。仍失败请通过工单提交客户端名称与报错原文。

流量、设备和年付是怎样计算的？

流量按自然月重置，不结转。设备数按同时建立的代理会话计算，电脑加手机同时在线会占用两台。年付价格为基础版 ¥150/年、旗舰版 ¥350/年、团队版 ¥850/年，适合用量稳定的用户。

能否解锁流媒体？游戏走哪类节点？

基础版提供基础流媒体解锁；旗舰版与团队版强调全节点原生解锁。若播放器仍提示地区错误，更换带解锁标签的节点并清除应用缓存。对战类游戏优先使用旗舰版 IPLC 分组，把游戏进程从规则模式中独立出来。

官方下载在哪里？会不会捆绑陌生软件？

客户端请从其各自官方渠道获取，MOCClouc 官方网站只提供订阅与导入说明。本页下载相关按钮均为站内锚点，不会跳转到未知安装器。若有人发送“已破解的一键包”，请忽略，以免订阅泄露。
